# PANDUAN SUPER SIMPEL: Upload Semua Produk ke Tokopedia

> Update 2026-09-27: riset 290/290 SELESAI. Berat & foto sudah terisi otomatis.
> Yang mengklik upload tetap **Anda sendiri** di akun Tokopedia Anda. Tidak ada yang otomatis.

## Cara kerja (gambarannya)

1. Anda **download 2 file**: (A) data semua produk dari website Anda, (B) template resmi dari Tokopedia.
2. Anda **copy-paste** dari file A ke file B.
3. Anda **upload file B** ke Tokopedia. Selesai — produk muncul di toko Anda.

## Langkah 1 — Download data semua produk (2 menit)

1. Buka link CSV terbaru dari saya (atau website Anda → scroll bawah → **Admin Login** → tombol hijau **Download Data Semua Produk (Tokopedia)**).
2. File bernama `tokopedia-semua-produk-....csv` terdownload. Simpan, jangan dihapus.

## Langkah 2 — Download template resmi Tokopedia (3 menit)

1. Buka **Tokopedia Seller** di komputer/laptop (bukan HP): `seller.tokopedia.com` → login.
2. Menu kiri: **Produk** → **Daftar Produk** → **Atur Sekaligus** → **Tambah Sekaligus**.
3. Pilih **Template tanpa Varian** (produk Anda tidak punya varian di website).
4. Pilih kategori yang sesuai (maksimal 10 kategori per template) → **Download Template**.
5. File Excel template terdownload.

## Langkah 3 — Copy-paste (cicil, jangan sekaligus 290!)

1. Buka kedua file di Excel/WPS: file CSV dari Langkah 1 dan template dari Langkah 2.
2. Di template, isi hanya sheet **[ISI]** (ada contoh di sheet "Contoh Pengisian").
3. Pindahkan kolom satu per satu:
   - Nama Produk ← kolom "Nama Produk" (maksimal 70 huruf — persingkat bila perlu!)
   - Harga, Stok, SKU, Deskripsi ← kolom yang sama namanya (harga & stok = angka saja)
   - Berat Gram ← kolom "Berat Gram" (sudah terisi semua dari hasil riset!)
   - Foto ← copy link dari kolom "Foto 1" (link foto website Anda, langsung bisa dipakai)
   - Kode Kategori ← pilih dari sheet "Daftar Kategori" di template (WAJIB kode Tokopedia!)
   - Kondisi = Baru, Status = Aktif
4. Kolom berwarna **merah/bintang** di template = wajib, jangan dikosongkan.
5. Lihat kolom **"Status Data"** di file CSV:
   - `OK — siap copy ke template` = aman, lanjut.
   - `KURANG — perbaiki dulu` = baca kolom "Catatan":
     - **STOK 0** → hapus baris itu dari template (upload nanti setelah restok).
     - **berat/dimensi perlu verifikasi** → produk bertanda [SEDANG]: timbang dulu bila sempat.

## Langkah 4 — Upload ke Tokopedia (5 menit)

1. Simpan template yang sudah diisi (Ctrl+S).
2. Kembali ke **Tambah Sekaligus** → **Upload File Excel** → **Pilih File**.
3. Tunggu selesai → klik **Ke Daftar Produk**.
4. Produk yang gagal akan dilaporkan Tokopedia (+ email) — perbaiki, upload ulang.

## Catatan penting

- Coba **2–3 produk dulu** (hapus baris lain di template), cek hasilnya, baru lanjut sisanya.
- 60 foto format .webp sudah otomatis diubah jadi .jpg di kolom Foto — bila Tokopedia
  menolak salah satunya, beri tahu saya, saya buatkan link khusus.
- Barang 100kg ke atas (treadmill, alat DHZ) sebaiknya aktifkan **Asuransi pengiriman = Ya**.
- Kalau kategori produk Anda lebih dari 10 jenis, ulangi Langkah 2–4 per kelompok kategori.
